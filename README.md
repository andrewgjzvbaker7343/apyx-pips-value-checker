## Overview

APYX Pips Checker is a standalone web page for examining pips linked to Ethereum, Base, and BNB wallet addresses. It obtains the available Season 1 and Season 2 pip data and displays the lookup in a compact format for fast review.

Beyond the wallet lookup, the page can estimate an implied APYX airdrop value. Users can test different assumptions based on TVL, an FDV/TVL multiple, or market capitalization. Each lookup can also be represented by a shareable wallet URL for later access or distribution.

## What It Does

- Looks up Season 1 pips for a wallet
- Looks up Season 2 pips for a wallet
- Works with Ethereum, Base, and BNB addresses
- Produces an implied APYX airdrop estimate
- Supports TVL-based valuation scenarios
- Supports FDV/TVL ratio scenarios
- Supports market-capitalization scenarios
- Creates links that can be shared for wallet lookups

### What networks can I use?

Wallet addresses from Ethereum, Base, and BNB are supported.

Yes. When data exists for the submitted address, the tool retrieves Season 1 and Season 2 pips.

### What determines the implied APYX estimate?

The estimate is modeled from the selected TVL, FDV/TVL ratio, or market capitalization assumptions.

Yes. The checker generates a link for an individual wallet lookup that can be copied and shared.

No separate installation is required. Use the hosted page, or clone the repository and open its HTML page locally.
